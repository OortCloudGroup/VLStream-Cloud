# 自有云盘接入数据集管理：接口需求

状态：TODO，等待云盘服务提供接口和测试样例。本文是建议的对接契约，不要求云盘沿用示例路径。

## 目标流程

用户在 VLStream 选择“自有云盘导入”，输入分享链接及可选提取码，选择文件/目录和目标数据集。
VLS 后端校验分享权限、获取文件列表和下载授权，后台拉取内容到当前 MinIO，并按现有图片、视频、ZIP格式导入。
不依赖网页抓取、浏览器登录态或人工从网页复制临时下载地址。

## 请云盘同事提供

| 能力 | 必需输入 | 必需输出 |
| --- | --- | --- |
| 分享解析 | shareUrl/分享ID、可选提取码、调用方身份 | shareId、文件/目录类型、根节点ID、分享名称、过期时间、是否允许下载 |
| 文件列表 | shareId、folderId、cursor、pageSize | items、nextCursor；每项有fileId、parentId、name、relativePath、类型、sizeBytes、version/ETag、修改时间 |
| 文件详情 | shareId、fileId、version | 稳定文件ID、字节数、文件版本、可选SHA-256、下载权限 |
| 获取下载地址 | shareId、fileId、version | URL、expiresAt、可选必须携带的headers、是否支持Range、是否可服务器直接访问 |
| 刷新下载授权 | 原fileId/version、分享授权 | 同版本的新URL/请求头；文件已变更时返回明确错误，不能拼接不同版本的内容 |
| 错误约定 | 各接口 | HTTP状态和稳定错误码：分享不存在/过期、提取码错误、无权限、文件已变更/删除、限流、临时故障 |

目录层级需能递归遍历，列表应分页；文件大小必须是64位字节数，支持至少4 GiB。
下载建议支持`Range: bytes=start-end`及`If-Match`或等价版本约束，返回206和正确Content-Range，
这样后台下载中断后可以继续；如果不支持，请明确说明，VLS会按整文件重试。

## 身份、网络与有效期

- 提供服务端调用方式：服务凭据、OAuth或现有统一身份体系；说明租户/用户/分享访问权限如何校验。
- 说明鉴权字段、签名算法、有效期、时钟偏差容忍度、限流及重试建议。不把密钥写入此文档或示例日志。
- 下载URL必须能被VLS后端访问；如果只能内网访问，提供域名、端口和网络要求。
- 说明单次分享的最大文件数量、单文件大小、下载并发、下载URL有效期及刷新方式。
- 分享过期或撤销后，VLS停止继续下载；已经合法导入的数据保留为独立样本，不自动删除。

## 最小可联调样例

1. 一条仅含1张图片的分享链接，提供文件ID/大小/摘要作为核对依据。
2. 一条包含多层目录、图片和ZIP的分享链接。
3. 一条有提取码的链接、一条已过期链接及对应预期错误。
4. 一个可分段下载的大文件，确认断点续传、授权刷新和文件版本变化行为。
5. OpenAPI/Swagger、curl示例或接口文档任选一种；说明测试账号和测试环境。
