# 训练数据集的 MinIO 存储

新生成的完整训练包保存到平台现有 MinIO。原始图片、人工标注记录、完整训练包和算力上的工作目录分别承担不同职责：

| 内容 | 保存位置 | 用途 |
| --- | --- | --- |
| 原始图片 | 平台对象存储 | 浏览、标注、生成版本 |
| 标注与版本快照 | MySQL | 编辑、追溯、固定训练输入 |
| 完整训练 ZIP | MinIO | 保存固定版本的图片、原生标注、类别和划分，供训练与下载 |
| 运行目录 | 所选默认 GPU / AutoDL 实例 | 本轮训练读取的工作副本 |

本次只切换新生成数据集。历史 SSH 目录不批量迁移，也不自动删除；旧路径继续按原方式使用。

## 生成与下载

算法标注页点击“生成”后，后台短事务固定版本，再在事务外制作并保存完整 ZIP。四类格式复用现有生成器：
分类目录、检测 TXT、实例分割像素掩膜 JSON、语义分割 PNG，以及 `dataset.yaml`、`vls-dataset.json`、
`version.json` 和相对路径校准清单。包内不带 GPU 绝对路径或执行脚本。

上传后回读校验大小和 SHA-256，只有 `READY` 才更新当前数据集引用。生成期间如果标注、类别或划分发生变化，
包作为历史固定版本保留，当前数据集不会被错误标为已生成，需要重新生成。生成失败不会覆盖旧的已生成引用。

新引用以 `vls-dataset://UUID` 表示，关联服务器保存的租户、数据集、版本、固定 OSS 配置、桶、对象键、大小和哈希。
这是内部版本标识，不是公开下载地址。页面展示“MinIO 训练数据包”。导出直接从 MinIO 下载，校验后输出 ZIP，
不要求原 GPU 主机在线；历史目录仍沿用原 SSH 导出。

## 训练与类别依据

- 默认 GPU：开始训练时读取已生成 MinIO 包，按版本复制到独立运行目录，重写 YAML/校准清单的运行路径，
  加入平台训练脚本，通过原有预检后入队。任务保存固定对象引用与运行路径。
- AutoDL：后台先把本轮冻结快照生成并校验为 MinIO 包，再连接所选实例。后续重试只读取该固定包，
  不重新采用当前可编辑数据集；实例上继续使用本期 Python 训练方式。
- 默认训练的后续转换、模型类别归档、数据集删除前的类别快照，优先使用该轮固定版本。
  任务重新训练后，旧模型不能借用新一轮的类别配置。历史训练若项目已改用 MinIO，须从原训练 `args.yaml`
  读取原始数据集依据，不能直接改用当前项目的新版本。
- 已保存的冻结引用不能通过普通编辑接口替换；新数据集在重新训练时选择。数据集编辑仍使当前生成引用失效，
  不改变已入队任务使用的历史版本。

智能标注还需要未标注的预测样本，本期继续使用其独立快照和已有 MinIO 图片链路，不拿纯训练 ZIP 替代预测输入。

## 清理与部署

新增 Flyway `V1_2_0_026__training_dataset_object_storage.sql`。迁移记录数据集制品和默认算力缓存归属，
为明确生成过旧训练目录的数据集补充历史缓存标记。更新服务后使用现有 Flyway 流程执行，不手工修改旧迁移。

生成领取与删除共用数据集行锁，`PENDING/BUILDING` 制品阻止删除；归档 I/O 不持有该锁。
删除按固定对象清单清理本数据集各版本训练包，并保护其他数据集仍引用的对象。纯 MinIO 数据集不连接 GPU；
只有登记过默认算力缓存或仍有历史绝对目录时才执行原远端清理。缓存连接身份变更、未知文件、符号链接等继续拒绝清理。
训练历史、模型文件和独立类别快照仍按原规则保留。AutoDL 实例与云端工作目录不在本次自动删除范围内。

制作/下载 ZIP 会使用平台临时磁盘，配置项 `vlstream.training-dataset.temp-dir` 可指向容量充足的位置。
默认展开上限 32 GiB（`vlstream.training-dataset.max-expanded-bytes`），单条目 128 MiB、图片 25 MiB、最多 100000 条目。
临时文件在处理结束后删除；持久训练包保存在 MinIO。

本地 Java 8 编译与 145 项定向测试、前端构建通过；其中 8 项实际使用独立 MySQL/MinIO 验证四类训练包的上传回读下载与一致性。
证据位于 `codex/dataset-minio/RESULTS.md`。真实 GPU 训练、正式业务库迁移和业务服务重启需另行验收。
