# 视频切图

入口：数据集 → 视频行“视频切图”，或视频详情中的“视频切图”。

## 使用流程

1. 上传MP4/MOV视频，等待导入记录变为完成。
2. 点击视频切图，设置开始/结束时间、间隔和最多图片数。默认从0秒开始，每1秒取1张，最多100张；
   结束时间留空表示直到视频结束，结束时间点不包含在范围内；每次最多1000张。
3. 提交后后台执行，原视频不删除。关闭页面不影响已提交的任务，进度在导入记录中以“视频切图”显示。
4. 切图结果作为JPEG加入同一数据集，初始未标注、未划分。与已有样本内容相同的图片不重复入库。
5. 打开图片详情可查看来源视频及实际帧时间；同一图片可保留多个来源关系。
6. 物体检测数据集点击“进入标注”，使用已有图片标注编辑器标注切出的图片，再进行训练/验证集划分。

## 处理边界

- 使用现有MinIO中的稳定对象键，后台流式下载并校验原文件大小/摘要，随后通过JavaCV/FFmpeg解码。
- 打包与现有JavaCV 1.5.10对应的Windows x86_64及Linux x86_64 FFmpeg运行库，不要求操作人员额外安装命令行FFmpeg。
- 按设定时间寻找该时间点之后的实际视频帧，并记录请求时间与实际时间，不能把请求时间伪装为精确帧时间。
- 视频帧率低于切图频率时，相同实际帧只提取一次。结束时间超出时长时截到视频结尾。
- 限制开始/结束时间在24小时内、间隔0.1至3600秒、最多1000帧、视频分辨率不超过4000万像素；
  一个任务的解码处理预算30分钟。原数据集容量限制继续有效。
- 没有可解码视频轨道、文件损坏、范围无效、存储失败或空间不足时，任务失败并显示原因；
  未完成整批登记的生成图片会清理，原视频与历史数据保留。失败任务可重试。
- 图片与来源关系在同一事务登记；重复请求处理中复用同一个任务，重复切图按内容去重。
- 视频原文件仍不直接参与图片训练，切图结果标注后才能进入图片数据集划分。
- 本功能为间隔切图，不提供目标跨帧跟踪、自动标注或视频时序标签。

## 后端接口与迁移

- `POST /vlsData/video-frames`：datasetId、videoId、startSeconds、endSeconds、intervalSeconds、maxFrames。
- `GET /vlsData/datasets/{datasetId}/samples/{sampleId}/video-origins`：读取当前样本的来源视频与时间点。
- 任务沿用`/vlsData/imports`及重试/取消接口，任务类型为`video-frames`。
- Flyway：`V1_2_0_014__dataset_video_frame_origins.sql`，增加来源关系表和任务进度说明。
- 切图属于后台任务，不调用GPU训练，不改动远端训练目录。更新后端并执行新迁移后生效。

验收证据保存到`codex/video-frames/`，以实际解码生成的图片和MySQL/MinIO记录为准。
