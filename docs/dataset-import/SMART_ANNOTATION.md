# 四类智能标注与训练

## 视觉大模型 API

从「算法仓库 → 算法训练平台 → 大模型标注」进入，选择数据集、现有已授权的提供商和模型，可补充标注要求。「大模型管理」用于维护提供商、授权和模型设置。任务冻结输入版本、标签、模型和提示词，并按所选提供商授权发送待标注的图片。支持方向已校正且不超过 8 MiB 的 JPEG 或 PNG，原图像素上限为 4000 万。新任务无需人工种子、已生成的训练集或 GPU 节点。

分类返回一个类别，检测返回原图坐标和类别。实例和语义分割使用模型返回的轮廓生成可编辑 PNG 掩膜，支持保留孔洞和分离区域。语义分割把跨类别冲突像素留为空白，与其他未归类像素一起交给人工处理。实际掩膜质量取决于模型对样本的定位表现，建议先用少量代表性图片验证。

默认阈值为 0.50。整张图片的每项置信度都严格高于阈值，且通过标签、坐标、掩膜和当前数据校验，后台才将候选写入正式标注。模型自报分数是估计值。等于或低于阈值、缺少分数、跨类别框冲突和仍有未归类像素的图片需要逐图确认。非法结果记为失败，手工修正后的候选沿用现有编辑器、数据集版本和训练链路。已通过的正式标注会使旧训练数据包失效，可重新生成训练包。

逐图调用状态持久保存。失败图片可显式重试，已确认数据和其他候选保留。授权变化停止剩余调用，取消后不再提交新图片，也不采纳迟到结果。中断或超时的请求可能已被上游处理，由用户决定是否重试。迁移 `V1_2_0_077__smart_annotation_vision_api.sql` 增加视觉 API 的任务和逐图记录字段。

## 算力节点与执行队列

主动学习和指定模型创建任务必须选择 GPU 设备（请求字段 `computeNodeId`），复用正式训练的算力选择器和后端准入。免费公司节点使用 `SHARED_GPU_QUEUE`，与各环境正式训练、智能标注共享物理 FIFO 和租约。私人节点、已完成付费开机的节点复用原环境、本人占用与计费检查；标注页不代为开机或产生报价确认。

可用图片和主动学习种子排除 macOS 辅助文件 `._*`、`.DS_Store`、`__MACOSX/`，保留历史记录，不把这些元数据文件交给图片解码器。其他解码失败提示样本ID与文件名，供定位原始数据；不自动覆盖或删除人工标注。共用任务表的本地单/多租户后端应同时加载支持 `smart_round_id` 的队列消费者，避免旧消费者按正式训练读取标注任务。

数据集可跨批次累积样本，没有固定样本总数上限；单个冻结版本最多包含 100000 个样本。模型和标签选项分批读取样本元数据及标签计数，涵盖当前数据集的全部样本。创建和开始下一轮时校验并冻结完整输入。冻结版本仍以 JSON 保存，实际可处理规模受数据库单次写入容量、后端内存与算力节点资源影响。

新建主动学习前，先把待标图片和已有标注准备在同一数据集，再生成训练数据集。下拉列表将未生成或训练包已失效的数据集置灰，并在表单内提示生成步骤。提交时再次检查训练包状态。指定模型可直接对未生成的数据集预标注。主动学习的后续轮次以新确认的标注自动冻结输入。

每轮冻结输入和所选节点配置，通过验证过主机身份的 SSH 连接上传图片与脚本。主动学习先训练后推理，指定模型只推理；四类均使用节点标准 Python 环境，新增任务不走旧全局 SSH/Docker 入口。模型从对象存储校验下载，预置模型使用节点官方缓存；共享池只接受官方权重或本租户本人在可信池归档的模型。历史未归档的服务器绝对路径不能直接迁移到新节点。

轮次存入 `vls_cloud_training_job.smart_round_id`，其 `training_id` 为空，不伪造正式训练记录。PT、类别和预测校验、预测事务导入完成后才释放算力租约。新轮次有符合自动确认条件的候选时，释放租约后交给后端执行自动确认，再进入 `REVIEW`。导入幂等，释放或回存失败保留现场并自动重试，期间不能开始下一轮。算力阶段取消先记录请求，等本任务进程身份核对及退出确认，不能把 SSH 断线当作已停止。日志与阶段进度由节点任务回存。新迁移为 `V1_2_0_074__smart_annotation_compute_queue.sql`；后端更新前必须完成迁移。历史未选择节点的任务不会自动改写执行目标，应结束后重新选择节点创建。

四类均支持主动学习和指定模型。分割编辑器提供画笔、橡皮、撤销；语义分割提供未归类区域填充。分类选择整图类别。已有不兼容标注替换前保存版本。人工编辑使用版本摘要检查并发冲突。

数据集管理现在开放四类创建、编辑、训练目录生成；分类/分割从`/dataset-annotation`进入人工标注，检测沿用原编辑器。正式训练按四类匹配基础模型及数据格式，生成PT并允许保存到模型列表、供后续智能标注使用。分类和语义分割的主动学习门槛按每类覆盖图片数，检测/实例按实例数。

新轮次预测回存后，主动学习和指定模型都会自动确认通过校验的整张图片。图片须有预测，模型返回的每项结果的置信度都严格高于任务阈值，包括随后合并的同类重叠框，并通过各标注类型的结构、类别匹配、当前轮次和样本归属校验。空预测、任一结果的置信度小于或等于阈值、类别未匹配或冲突的图片整张保留待确认。后端在写入时重新检查图片和正式标注是否被更改，存在变更的图片仍待处理。任务在此期间显示 `AUTO_CONFIRMING`，结束后进入 `REVIEW`。历史已回存的结果保留原确认状态。

逐图确认、按页确认和手动点击“确认本轮已通过标注”仍可使用。手动批量确认校验审核页显示的结果，目标检测使用合并后的框，置信度可等于任务阈值。手动发起本轮批量确认时，检查本轮跨页待确认图片，状态为 `CONFIRMING`。自动和手动的本轮批量确认都通过逐图事务及持久游标保存结果。完成任务仍以已确认并写入的正式标注为准。

系统基础模型为YOLOv8检测/分类/实例分割及Torchvision DeepLabV3语义分割。首次使用需下载官方权重或预置缓存。语义分割自有PT须为平台生成的DeepLabV3检查点，不能任意替换。代码参考Ultralytics 8.3.240、PyTorch 2.5.1和Torchvision 0.20.1；正式GPU容器依赖需现场核对。

四类的主动学习和指定模型共用现有GPU队列。非检测正式模型只完成PT并进入模型保存链路，不自动套用检测专用的ONNX/OM/RKNN转换；设备适配不在本次范围。迁移`V1_2_0_022__four_type_annotation_payloads.sql`接续021，扩展任务类型、掩膜容量、进度和后台确认字段。

单掩膜最多8MiB、单图载荷最多24MiB、最多4000万像素。单轮远端结果文件目前限制64MiB，超限任务明确失败，应拆分数据集；不把无效或过大结果计为成功。

本轮证据位于`codex/smart-four/`。四类均通过真实CPU小型合成数据训练和推理，证明链路可执行，不代表业务精度。未部署正式服务、未执行业务库迁移、未在真实GPU上训练。

## 两种模式

目标检测预标注展示及批量确认采用同类NMS，IoU大于0.45时保留最高置信度框，正式标注写入合并后的框。不同类别IoU大于0.7的框保留，并提示逐图复核。自动确认、本页批量确认和后台一键确认都会将这些图片留待人工处理。单图编辑器允许人工调整、删除、补框和明确确认相互遮挡的不同类别目标。规则适用于新预测和历史PENDING记录，原始预测仍可追溯，已确认结果按保存内容展示。分类、实例分割和语义分割使用各自的载荷规则。

- **指定模型**：选择已有 PT 模型或主动学习成功轮次的模型，对当前未标注图片进行批量推理。新轮次符合自动确认条件的图片直接保存，待确认图片可逐图修改类别、移动框、调整坐标和大小、补框或删除框，再确认保存。也可以显式确认本页符合条件的结果。
- **主动学习**：用数据集已确认标注训练本轮检测模型，对其余图片推理，优先展示平均预测置信度较低或没有检测框的图片。确认或跳过本轮难例后，且本轮至少确认一张图片，可再次训练下一轮。未确认预测不作为训练标签。

初版仅支持目标检测，权重通过 Ultralytics 加载后必须识别为 `detect`。基础算法权重仅用于主动学习；指定模型使用已训练模型或成功的主动学习轮次。模型未知类别不按数字下标猜测对应关系：同名标签自动匹配，未匹配类别需要用户在确认页选择标签。

首次主动学习默认要求每类至少 10 个标注框、至少 101 张可用未标注图片，最多 4 轮。指定模型至少需要 1 张可用未标注图片。这些门槛参考 EasyDL，属于工作流条件，并不保证达到某个模型精度或标注节省比例。

```yaml
vlstream:
  smart-annotation:
    min-boxes-per-label: 10
    min-unlabeled-images: 101
    max-rounds: 4
```

新任务通用默认值为预测阈值 0.25、每轮训练 20 个 epoch、每轮难例 50 张，前端和后端缺省值一致。每轮训练可选 1–100，难例数量可选 1–500（候选不足时取实际数量），预测阈值为 0.05–0.95。开启自动确认的轮次中，目标检测和实例分割的推理以 `min(0.05, 预测阈值 / 2)` 作为保留候选的阈值，以留下低分结果供人工检查。图像分类保留最高分的类别，语义分割保留推理得到的类别区域。四类任务的自动确认均使用用户设定的预测阈值。指定模型模式不执行本轮训练。推理和训练当前固定使用 640 输入尺寸；主动学习训练 batch=4，新节点任务 workers=0。难例排序使用置信度启发式，不能据此估算真实错误率。

## 状态与数据归属

任务按 `QUEUED → PREPARING → RUNNING → REVIEW → COMPLETED` 转移。新轮次有符合自动确认条件的候选时，先经过 `AUTO_CONFIRMING` 再进入 `REVIEW`。失败进入 `FAILED`，可重试同一轮输入；重试会创建全新的远端尝试目录和容器名。取消排队或运行中的任务先进入 `CANCEL_REQUESTED`，调度器停止本任务后进入 `CANCELLED`。已确认标注始终保留。

任务、轮次、预测分别存储在 `vls_smart_annotation_task`、`vls_smart_annotation_round`、`vls_smart_annotation_candidate`。每轮引用既有数据集版本快照，保留模型 SHA-256 和模型路径。图片仍由当前对象存储持有，远端执行读取稳定对象键，不下载浏览器签名链接。

公司免费共享 GPU 的每轮执行确认退出后登记工作目录清理。成功轮次在模型和类别回存校验、预测导入完成后登记，失败或取消在确认退出后登记。后台按任务身份清理数据集副本、预测工作文件及中间产物，断线后继续重试。审核和后续轮次读取平台保存的原图、预测和模型。已记录的日志尾部保留在数据库。

确认时在同一数据库事务内校验租户、数据集、当前轮次、图片内容标识、标签归属和坐标，拒绝覆盖已被人工标注的图片，然后调用原标注保存服务，更新图片进度并使旧训练目录失效。重复确认不会重复写入。本页批量确认中的任一图片发生冲突时，该页提交整批回滚。后台本轮批量确认按图片提交，冲突图片留待处理。完成任务保存结果版本，仍待确认的预测不加入该版本。

无目标预测允许手工补框或跳过。跳过不会生成空的正式标注，也不会计入已有“有标注图片”统计；本次不扩展负样本训练能力。视频仍需先切图。

创建与轮次推进使用原数据集锁。进行中的智能标注任务会阻止删除数据集；用户先结束或取消任务。数据集的一般人工编辑仍允许，确认时检查冲突。训练/验证划分尊重已有验证集，并检查相同内容不可跨集合。

## GPU 执行与上线

新增 `smart_annotation` 容器类型，复用 `GpuTrainingSchedulerService` 的持久 FIFO 和整卡独占策略，与正式训练共享队列。智能标注完成不会触发正式训练模型发布或 ONNX/OM 转换。沿用现有全局 SSH 连接、容器镜像和挂载配置。

执行文件位于 `${vlstream.training-container.host-data-dir}/vls-smart-annotation/<taskId>/<roundId>_<attempt>/`，包含冻结图片、训练标签、脚本、日志、模型与结果。模型必须位于现有容器数据挂载目录内。路径不使用用户提交的任意命令；取消仅针对该轮容器名。源 PT 权重复制到本轮独立目录后才加载。

上线需要应用 Flyway `V1_2_0_021__smart_annotation.sql`，更新后端并重启对应 JVM，同时更新前端。容器需具备现有 Conda Python、Ultralytics、PyTorch 和 CUDA 环境；主动学习使用的基础权重必须存在。当前单实例调度架构保持不变，不新增跨 JVM 分布式 GPU 调度能力。

接口前缀 `/vlsData/smart-annotation`，提供任务列表、创建、详情、候选模型/标签、预测分页、单图确认、批量确认、下一轮、完成、重试、取消和日志。客户端 ID 一律按字符串处理。

有智能标注权限的同租户成员可共同查看、审核和管理两类任务。取消只记录并停止对应任务的执行，已确认标注继续保留。重试及下一轮重新核验发起人的私人节点、付费实例和模型准入，使用大模型供应商时重新核验租户授权。原始算力日志仍受当前执行的个人归属保护。
