# 视频广场的对话式拓扑和 BIM 视图

在视频广场切换到「拓扑视图」或「BIM 视图」。还没有生成过页面时，画布显示内置示例：拓扑是带数据流动画的设备链路图，BIM 是可旋转的三维示意园区。示例会把当前授权目录中最多六台摄像头（在线优先）绑定为实时点位，其余点位标为“示意”。点击视图工具栏中 BIM 图标右侧的「AI」展开场景助手，再输入想看到的画面和操作，例如在 BIM 中先输入“生成三栋楼的园区，有道路、绿化和摄像头点位，支持昼夜切换”，看到园区后再输入“保留园区，加一个二层剖面”。同一人同一模式的后续描述在当前页面上修改。

拓扑连线表达用户设计的设备关系。BIM 根据文字绘制示意园区、楼栋和楼层，几何形状与点位由生成内容决定。用户需要真实施工几何或测绘位置时，需另外提供经核实的模型和数据。

## 从对话到可操作的页面

1. VLS 根据登录身份读取本租户、本用户在当前模式的已保存页面。浏览器提交当前筛选目录的候选设备，优先选择描述中点名的设备和已有绑定，其余按在线优先补足，默认最多 8 台；描述中要求“全部/所有摄像头”时最多 80 台。勾选「新页面」时，本次生成不参考当前页面源码和历次要求，原页面仍可回退。服务端向 WVP 核实权限，只把可用设备的别名和名称交给模型。
2. 后端通过本租户已授权的 OortCloud 账号调用聊天补全接口。默认沿用租户的已选模型，也可在侧栏「切换模型」为本次请求选择同一授权目录内的型号，服务端重新核对。系统提示词固定，请求内容依次包含可用摄像头、仍然生效的历次要求（最多 8 条）、当前页面源码和本次要求。
3. 模型二选一输出：完整 HTML 页面，或针对当前页面源码的 `SEARCH/REPLACE` 局部修改。局部修改逐段应用，没有改到的代码逐字保留，这样“保留园区，加二层剖面”不会丢失已有建筑、镜头、昼夜切换和摄像头绑定。某段修改找不到或对应多处时，服务端自动请求一次完整页面（再消耗一次模型额度）。
4. VLS 以 NDJSON 分段推送草稿。浏览器在只允许宿主引导脚本运行的草稿 iframe 中展示已到达的版面，侧栏显示进度和正在写入的代码。完整页面通过结构和大小检查后才保存，浏览器在新页面就绪后淡入替换草稿。
5. 页面在 `sandbox="allow-scripts"` 的不透明来源 iframe 中直接运行，CSP 禁止网络连接、外部脚本、样式、图片和表单提交。宿主在页面脚本之前注入：
   - `window.VLS`：`cameras`（别名、名称、在线状态）、`preview(id)`、`closePreview()`、`theme` 与 `on('theme' | 'cameras' | 'preview', fn)`。
   - 页面用到 `THREE` 时注入 Three.js r187 及 `OrbitControls`、`CSS2DRenderer`、`EffectComposer`、`UnrealBloomPass` 等扩展，并提供 `VLS.three.fit / flyTo / onPick / autoResize` 用于整体构图、平滑镜头、点击拾取和随对话栏自适应。
6. 实时视频位于 VLS 宿主页面。用户在页面中点击绑定的摄像头时，宿主核对当前目录并以浮窗或页面标出的 `data-vls-preview` 区域打开原播放器；页面传入示意点位或失权设备时只提示“示意点位”。
7. 页面运行错误、未处理的 Promise 异常和资源加载失败会带上对应源码行回报到侧栏，用户可一键请模型修复，或回退到上一版。页面尝试跳转会被阻止并重新载入；12 秒没有心跳的页面会被停止。

## 保存、恢复与回退

- 每人每种模式一行记录（`vls_video_square_scene`）。`scene_json` 保存当前页面、摄像头别名绑定、最近 30 条修改记录和此前 5 个版本，无需额外数据表。读取接口不返回旧版本源码，只返回可回退次数。
- 刷新或重新登录后，页面和对话记录按修改记录恢复。
- `POST /vls/video-square/scenes/{mode}/undo` 以新版本号恢复上一版，并发修改返回 409。停止生成、模型失败或版本冲突都保留已有版本。
- 工作区昼夜外观只保存在各浏览器本地，并通过 `VLS.theme` 告知页面。

## 容器交付与流式预览

升级时一起交付含页面运行环境的 VLS 前端和含生成接口的后端。页面运行时、Three.js 和草稿渲染器在前端构建时打包为字符串，进入拓扑或 BIM 视图时才加载（约 210 KB gzip），不访问 CDN。数据库沿用 `V1_2_0_084__video_square_scene.sql` 建立的个人视图表，本次增强没有新增迁移。各后端副本共用业务库。用户修改个人页面无需重建镜像、写入容器文件或分配新域名。

网关需要将应用 API 前缀下的 `/vls/video-square/scenes/` 转发到 VLS。读取和回退接口返回 JSON，生成接口返回 `application/x-ndjson`。后端逐段刷新响应并设置 `X-Accel-Buffering: no`。Ingress 或反向代理应对该路由关闭响应缓冲，并将读取超时设置为能覆盖模型等待时间。

## 限制

- 描述最长 2000 字，每轮最多 80 台候选设备，单个页面最大 128 KB。非 GLM 模型的输出上限为 16K tokens，上游拒绝时降为 8K。
- 每轮生成的视觉细节和交互正确性取决于模型与描述，以页面实际运行为准；运行错误可通过侧栏修复或回退。
- 页面与应用会话隔离，但仍能在自身 iframe 内运行任意脚本；它只取得摄像头别名、名称和状态。
