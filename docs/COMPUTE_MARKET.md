## AutoDL Pro库存草稿（`.040`，本地开发，未部署）

管理员从算力管理选择已安全配置的Pro节点，点击“Pro库存同步”。来源必须属于当前管理租户、产品为AUTODL_PRO、已有后端加密凭据/API模式/控制总开关，且已按`.039`登记非秘密稳定账号范围。账号范围来自既有登记引用，不以token哈希、节点名称或临时会话推断，不声称已验证供应商账号真实ID；同一账号引用和实例ID形成与公共身份一致的唯一键。无新凭据输入渠道或角色授权，来源不足、普通/企业产品返回明确未接入提示。

复用Pro适配器的固定域名、无重试/重定向、安全错误与加密凭据。根据[公开Pro文档](https://www.autodl.com/docs/instance_pro_api/)核对 `POST pro/list`、`page_index/page_size` 和 `data.list/max_page/result_total`，从1开始分页，单页20，最多50页/1000条，超限明确失败。全页形状/总数稳定、去重完整后才一次事务幂等写入 `vls_compute_provider_inventory`；同账号同步用MySQL命名锁跨进程互斥，写入前重新校验来源权限/身份/凭据，期间改配置则丢弃结果。重复页字段矛盾、空中间页、缺必要字段、总数变化、授权/网络失败不部分提交；完整空响应或缺失实例也不删除旧记录，不猜供应商释放。

草稿只保存白名单身份、规格、GPU配额、标准化运行状态、时间及价格原值。供应商任意名称不回显，root_password、jupyter_token、SSH命令/地址及完整响应不保存/输出；Apache HTTP wire/header日志关闭，错误不附供应商响应。只确认官方`running`，其余状态保持UNKNOWN；规格配额不等于空闲卡或GPU库存，观察五分钟过期转未知。管理员可单独查询草稿状态与价格，复用原status/snapshot和cost方法；价格币种、缩放、单卡/整实例口径和完整停机终态仍未核实，草稿不可自动上架，现有Pro收费上架/启动门禁保留。

观察时间取HTTP查询起始时刻，较慢分页完成不会把旧状态重新标成新鲜。分页结果保留期间较新的只读状态；旧只读查询若遇到更新观察则拒绝覆盖并提示刷新。再次同步替换已过期观察时不沿用旧状态时间。草稿本身始终不提供调度或上架资格。

发现与接入/上架分离：同步完全不写计算节点、SSH/用户环境、公共占用、任务或计费记录。按既有公共键只读显示是否关联节点；未关联项显示“待手工接入”，指引管理员通过原接入实例流程核对SSH、实际逐卡编号、Pro配置及公共账号身份，环境检查和明确免费供给按原权限另行完成。没有自动SSH配置、批量公共身份重绑、自动上架或第二套队列。已占用、已隔离和历史工作区不会因草稿同步变为干净。

部署授权后由标准Flyway在`.039`后执行新增 `V1_2_0_040__compute_provider_inventory_drafts.sql`，只建草稿表/索引，不种入实例、秘密、权限或价格。只在本任务独立临时MySQL验证，未操作业务DB。受控测试与UI证据见`codex/compute-market-reference/RESULTS.md`；全部供应商HTTP被mock，无真实API、购买/启停或付费验收。

## 厂商配置

服务端属性 `vlstream.compute.cloud-control.enabled` 默认 `false`。开发及受控测试没有启用真实账号；后续启用须先得到具体账号、实例、启停范围和费用授权。
算力管理的“厂商接口配置”保存产品、实例 ID、ECS RegionId 和停止请求模式，以及后端加密凭据。留空保留凭据，更换实例/区域/产品须重填；停用手工模式可清除凭据。请求以敏感请求处理，不写浏览器缓存。

- 普通/未接入 AutoDL 产品当前没有已验证适配器，只显示控制台指引；通用、Pro、企业弹性 API 的资格与能力须分别核对，不声称官方完全没有通用接口。
- 容器 Pro：固定官方域名，原始 Authorization Token，GPU 模式 `power_on`，`power_off`，GET JSON body 查询 `status/snapshot`；HTTP 自动重试和重定向关闭。只映射官方确认的 `running`；其他状态/错误保持未知，完整停止枚举仍需厂商文档，不能宣称关机已自动确认。
- ECS/EGS：使用已购 InstanceId/RegionId，官方 Java 8 RPC SDK 4.5.30 签名，禁自动重试，不调用购买/释放。本仓使用兼容现有 Java 8 依赖的 V1 SDK，不宣称它是最新推荐 SDK；后续升级 V2 可独立进行。
- ECS 启动的 RequestId 只代表受理。运行状态、GPU 规格配额、实例锁定、环境/占用和调度资格分别检查。DryRun 和售卖库存不保证重启成功。
- `StopCharging` 回收计算资源，重启可能无库存，磁盘等仍计费且公网 IP 可能改变；`KeepCharging` 持续收费。厂商可能忽略不支持的停止模式，以查询得到的实际模式为准。

整机只有一个启停操作记录。提交标记先独立持久化，再请求厂商；超时/网络不确定不重发。后台继续只读轮询；管理员“恢复挂起记录”只在十分钟后且厂商查询返回明确运行/停止终态时解除本地记录，不把旧请求宣称成功。未知/过渡态不能清锁。
市场列表刷新只读数据库。环境检查五分钟有效；登录消费者可从市场单独“刷新环境检查”，服务端只接受节点 ID，只检查已发布、启用、明确运行的实例，管理员须事先确认 SSH 主机身份。复用既有固定检查脚本，不接受命令、地址或路径参数，不初始化/下载依赖，不向消费者返回凭据或私有检查明细。

结算意图按使用记录唯一键去重，扣款前独立保存提交状态；超时/进程重启只查同一幂等键。后台账务只用可信账户、版本化费率和幂等用量记录，不依赖浏览器在线或短期平台 token。启停 worker 在当前操作条件更新成功的同一事务中，仅同步已有可信绑定的内部用量记录；未知转待对账、确认运行/停止保存 OBSERVATION。不会自动选付款人、创建费率/租用或扣款。现有训练与云开机端继续阻断收费供给；免费、自接外部算力不被阻断。

“查询价格参考”只读取并保存白名单观察：Pro `payg_price/origin_pay_price` 缩放单位、币种和整实例/单卡口径仍未知，不猜除 1000 或再乘卡数；ECS `DescribePrice(Hour,1)` 保存参考金额/币种及实例、磁盘、带宽等组件，不是已购实例实际折后成本。实际账单的延迟不能用现金金额 0 推断免费，未接入 BSS 实账自动换算。普通 AutoDL 需要人工核对成本。

真实收费接入仍需可信 GPU 计算成本、币种/缩放/整实例单位、价格生效规则和 Pro 完整状态/错误枚举；磁盘/维护等平台成本不得混入用户计算账单。磁盘回收与平台成本仍需核实，但不建立个人存储产品。不能把未知单卡原价乘卡数或用虚假 LLM 请求消耗 token 代替扣款。

## 平台授权与待补中转站契约

算力侧只读 `GET /vlsCompute/platform-authorization` 复用既有 `PlatformTenantClient.verifyToken`；验证本地 Authorization/blade-auth 对应当前已登录 VLS 用户与租户，再验证独立 accesstoken。多租户 token 必须来自该本地会话的既有平台绑定，并匹配平台用户/租户；单租户取独立 OortCloud 会话，不把本地凭据兜底为收费授权。结果只含安全身份与原因，没有 token、余额或密钥。该结果只在当前 HTTP 请求缓存，下一次操作重新验证；锁内再次检查资源配置，收费契约缺失时继续拒绝。

前端通过既有多租户平台登录或单租户 `startModelHubLogin(..., {returnToCurrent:true})` 引导授权，不新增权限或长效令牌。取消保留表单；查询失败/身份变化不执行操作。登录回调只返回原路径和选中卡，非秘密训练配置保留 30 分钟；本地会话 token 轮换后须服务端确认同一 VLS actor 方可恢复。回调不自动购买、开机、提交训练或扣款，用户仍需主动操作并经过当前服务端校验。停止维持现有资源 owner + power 权限和整机空闲限制，不用平台短期 token 额外阻止停机；没有给予新用户停止权限。

中转站同事最小提供以下文档及脱敏样本；这些是契约需求，不是已实现或猜测的字段/API：

1. 统一 SSO 稳定用户主体的服务端验证契约，平台用户即中转站个人用户，无额外映射表；账户切换/注销的规则。客户端不可指定他人付款人，应用 tenantId 只用于隔离，不查询或扣减租户余额。
2. 额度单位、可用余额查询、币种兑换版本/有效期与最小单位舍入；实际实例成本的来源、整实例口径和有效时间。
3. 原子个人余额扣减：可信 SSO 主体、整数额度、持久幂等键及不可变 GPU 计费区间；余额不足整体拒绝，不能靠先查余额再非原子写回，不扣个人磁盘费。
4. 按同一幂等键查询已提交扣款结果的方式、终态/未知错误码与重试、冲正/退款/对账语义。
5. 后端限权身份、个人付款作用域、轮换/撤销与超时；用户退出或浏览器 token 过期后仍可处理已有 GPU 用量，不保存浏览器 token 假装后台授权，不授任意用户代扣权限。
6. VLS 已实现免费公共库存的持久跨卡整机用户占用和保守隔离，产物回传清单与安全清理执行器仍待下一阶段；中转站不负责供应商操作或文件服务，停机不证明可复用。v3正文已保存，真实 NewAPI 服务鉴权及账本能力尚未核验。

以上缺失期间真实收费仍关闭；当前纯内部账务构件只接受受控测试绑定，没有外部扣款入口或后台真实扣款任务。无需现在提供真实密钥或账号，本次不接触付费 API。

## 建议账务契约与当前代码差异（2026-10-10）

以下是对本地 VLS 代码的核对，不是对实际 NewAPI 服务的验收。草案可沿现有节点、队列、厂商适配、身份校验和 outbox 机制扩展，但不能仅补一个真实 debit 网关后启用收费。

| 草案能力 | 当前实现及差距 |
| --- | --- |
| 统一 SSO 个人余额 | `ComputePlatformAuthorizationService` 复用可信平台校验及既有应用会话绑定，返回平台主体；不接收客户端付款人。实际 NewAPI 同一稳定主体断言、issuer/audience 或 opaque 校验契约、受限后台服务授权仍需双方核验。VLS shadow ID 不能作为余额用户；租户是应用隔离，不是钱包。没有建立独立账户映射。 |
| GPU与模型统一资金保护 | Gateway 仅内部 `availableQuota/debit/lookup`，没有v3商户资金API/冻结/退款或真实实现。ledger reserve**不是冻结资金**；既有消费须尊重冻结或等效资金保护，不能靠VLS单侧查余额证明。平台磁盘不占用户冻结。 |
| 整机用户独占与安全复用 | `.039` 新增免费公共实例持久占用，多卡同一可信 SSO 用户；无清理执行器，用过或历史工作区保持隔离。STOPPED/start failure 清计算 active key **不授权复用**，付费占用仍阻断。 |
| 仅GPU用户账单、平台成本分开 | 当前只有内部计算期间与单笔意图，无真实 GPU_COMPUTE 资金接口或周期资金保护；不建立 GPU_STORAGE 用户订单。磁盘/维护/最低费差额归平台，实账成本导入尚缺。 |
| 可信成本、起止与快照 | 费率使用BigDecimal、毫秒时长、整实例×2和不可变快照，参考价不激活。实际GPU计算价格/组件、币种兑换及可信事件待核实，OBSERVATION不是实际切换秒点。磁盘归平台成本；KeepCharging不证明供应商停收，但不授权延长用户停机后收费。 |
| 周期计量与整数最小额度 | 当前只在确认 STOPPED 后生成整期间一笔 charge，没有不重叠周期游标、周期冻结补足或分段改价。内部支持可配置小数 scale/舍入，尚未固定为草案的整数最小额度字符串与只扣整数部分；不能把现有可配置舍入当作新契约已完成。 |
| 同一用户跨实例余数 | 当前余数键含 tenant/payer/unit。v3要求统一个人跨GPU周期/实例串行累计、追溯未决分配与冲销；现有租户分开尾差不足，不把应用隔离误作多个个人钱包，平台磁盘成本不混入余数。 |
| 原子订单、资金流水与幂等 | 当前有本地唯一 charge、提交前持久 CAS、未知只查询旧 key 的受控测试。没有 NewAPI 资金事务、商户隔离、规范请求摘要、订单版本、业务 billing_slice 去重、退款上限和不可变资金流水；查无记录后的原键原请求重试语义也需真实契约。 |
| GPU低余额、停机缓冲与三方对账 | 云启停异步与未知只读恢复已有，真实扣费/余额提醒/资金保护窗口/自动安全停机和三方对账未接通，无人工客服。磁盘成本平台承担，无个人磁盘欠费。错误扣款仍纠正，停止按钮不是实际停机证据。 |
| 用户账单和验收 | 市场及训练可显示可用性并保留表单，收费始终拒绝。没有权威个人余额/冻结/周期GPU账单或资金验收，v3全部验收框未勾选；无用户存储账单，mock不代表真实联调。 |

## 本地策略阶段：默认规则与供应商差异

有界阶段增加 `ComputeBillingPolicy`，只估算默认3600秒GPU计算预留，提醒7200/1800秒、停机安全预算至少300秒＋轮询余量60秒，不预留用户磁盘费。阈值无效/可靠停机耗时未知或不足拒绝；无余额预测、提醒或自动停机执行器，完成动作仅KEEP_RUNNING，自动删除仅false。
配置/校验固定 `fault-compensation-enabled=false`、`supplier-minimum-cost-bearer=PLATFORM`，错误值拒绝。没有默认故障赔付/退款承诺；退款/冲正接口仍在设计契约保留纠正错误或重复扣款，实际未接入。`unpaid-storage-action` 已移除，不存在“转人工”服务或长期个人磁盘执行分支；不自动删除已由校验落实。

收费新增上架增加当前供应商节省停机证明校验；目前仅新鲜 PROVIDER_API/STOPPED/ECS/PostPaid/实际 StopCharging 且请求模式正确可通过此项，仍只是参考供给，不授权收费启动。未验证的普通 AutoDL/Pro、自有收费、过期/手工证据、普通/未知停止模式拒绝新增收费上架；免费、自接和取消发布路径保留。旧参考供给不自动更改或删掉，实际收费动作原有阻断保留。

ECS 关机后实际 KeepCharging 或未知模式，worker 仍可确认物理关机，但内部用量保持 RECONCILE，不能生成计算终点/结算意图。RECONCILE 表示待核对，不能据此继续向用户收取实际停机后的 GPU 费；用户计费截止与供应商停收时点须分别验证。只有当前已支持适配器确认的实际 StopCharging/PostPaid 可结束计算期间观察；OBSERVATION 仍不是实际秒点证据，数据归属和安全清理要求不改变。[ECS 节省停机模式](https://help.aliyun.com/zh/ecs/user-guide/economical-mode)

价格快照新增 `pricePolicy/providerPriceLockConfirmed/priceEvidence`：锁价须供应商证据，不由名称推断，普通AutoDL规则不能套Pro/ECS。未知历史快照拒绝新计量，未实现的 `SEGMENTED_NOTICE` 明确拒绝建立新收费期间；已存快照不追溯改价。未来分段规则见需求v3第6节与实际实现注记。[AutoDL 普通实例 FAQ](https://www.autodl.com/docs/qa/)

供应商释放周期最低时长可能与用户纯秒费用不同；差额由平台承担，相同期间/组件的可信实账差额只作平台内部核对估计，不进入用户费公式、不自动追收。实账导入/差额持久账本尚未实现，不能宣称已有内账跟踪闭环。[ECS 按量付费](https://help.aliyun.com/zh/ecs/pay-as-you-go-1)
供应商保留截止当前无已核实字段，仍未知；不根据观察时间编造 15/60 天日期。普通/Pro 的关机保留规则不套弹性部署，VLS 禁止自动删除也不能保证阻止供应商自动释放。供应商总账户欠费不是个人余额风控；转售/第三方使用许可仍须核对合同，尚未验证。

本阶段只改配置、守卫、错误说明及内部计算，不新增账务接口/定时扣费/自动开关机/删盘/通知器，无新数据库迁移。最新边界与未完成项见 [需求v3](NEWAPI_GPU_BILLING_REQUIREMENTS.md)及其实现注记。
